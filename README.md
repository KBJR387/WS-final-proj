# WS-final-proj
Finals Project - Online Portfolio

Description: I made a simple online portfolio about myself using HTML, CSS, & JS. It gives a brief rundown of My background, creative skills, and contact info ina single-page format. The design uses custom CSS for the responsive layouts, animations, and visual styling, while JavaScript gives the smooth scroll-triggered reveal effects which make the website seem modern and enhance its presentation.

Technologies Used: (Application: VSCode) (Coded using: HTML, CSS, JavaScript)
